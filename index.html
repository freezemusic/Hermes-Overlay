實驗：由 dashboard 匯入名單

用 Hermes dashboard 嘅 GET /api/profiles（預設 http://127.0.0.1:9119）。公開 API server 冇穩定嘅 profile 列表。匯入只填名稱同描述，唔會帶 API 金鑰。非 loopback 要貼 window.__HERMES_SESSION_TOKEN__，token 存喺鑰匙圈。
