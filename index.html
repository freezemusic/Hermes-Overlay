Hermes

呢度先係 Hermes Overlay 同連線設定。每個 Bot 嘅 SOUL.md 喺佢自己嘅面板。

金鑰只會寫入系統鑰匙圈，唔會放喺設定檔或者網頁。

第一次用：Gateway 位址填 http://127.0.0.1:8642，每個 Bot 填 API 金鑰，然後儲存。

留空就用離線示範。有位址就連自架 Hermes API server（預設埠 8642，Bearer API_SERVER_KEY）。具名 profile 走 /p/<profile>/；default 用唔帶前綴嘅路徑。每個 profile 自己一埠嘅話，喺該 Bot 填專用位址。

Bot 名單

「顯示」決定邊個 profile 出圓球。右鍵圓球可以隱藏，喺呢度剔返就顯示。隱藏保留金鑰；移除會刪金鑰，下次發現會再出現但要再填金鑰。

實驗：由 dashboard 匯入名單

連上 Gateway 時會自動發現 profile 並寫入設定：本機 Hermes 目錄（HERMES_HOME 或 ~/.hermes）、已存嘅 dashboard session token 對 GET /api/profiles、以及 /health 如果本身列出 profiles。新 profile 會出圓球，金鑰留空，要你填，唔會自動產生。圓球顏色讀 profile.yaml 嘅 ui_meta.hermes-bots.color（或 dashboard 同欄位）；冇顏色先用預設色。下面個掣只係再匯入到呢個表，仍然要儲存。

手動匯入用 Hermes dashboard 嘅 GET /api/profiles（預設 http://127.0.0.1:9119）。公開 API server（8642）冇 profile 列表。匯入只填名稱同描述，唔會帶 API 金鑰。Dashboard 即使係 localhost 都要 session token，否則 401。Token 係 dashboard 頁面嘅 window.__HERMES_SESSION_TOKEN__，唔係 API_SERVER_KEY，存喺鑰匙圈。

游標同穿透

光球（包括設定、看板同排程）預設半透明，滑鼠穿透，唔會接點擊或 hover。按住修飾鍵時，游標下面嗰粒光球先變實色、可以點；右鍵隱藏都只喺按住修飾鍵時先有效。放開就回復穿透。新訊息會由光球向畫面中心橫向展開成膠囊，顯示 5 秒之後收回。膠囊唔使按修飾鍵都睇到，但要按住先至點得入去。面板預設實色，游標喺面板上面就可以拖同點。按住修飾鍵時，面板變透明並穿透。輸入框聚焦唔使按住修飾鍵。

Linux 視窗管理員常用 Alt 拖移視窗（xfwm4 預設，GNOME／KDE 都常見）。揀 Alt 之後，Alt+click 可能去唔到呢個程式，設定就開唔返。可以用快捷鍵 Ctrl+Shift+Alt+H，或者系統匣選單「設定」。
