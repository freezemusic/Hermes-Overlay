設定

金鑰只會寫入系統鑰匙圈，唔會放喺設定檔或者網頁。

留空就用離線示範。有位址就連自架 Hermes API server（預設埠 8642，Bearer API_SERVER_KEY）。具名 profile 走 /p/<profile>/；default 用唔帶前綴嘅路徑。每個 profile 自己一埠嘅話，喺該 Bot 填專用位址。

Bot 名單

實驗：由 dashboard 匯入名單

用 Hermes dashboard 嘅 GET /api/profiles（預設 http://127.0.0.1:9119）。公開 API server 冇穩定嘅 profile 列表。匯入只填名稱同描述，唔會帶 API 金鑰。Hermes 0.21.6 嘅 dashboard 即使係 localhost 都要 session token，否則 401。Token 係 dashboard 頁面嘅 window.__HERMES_SESSION_TOKEN__，唔係 API_SERVER_KEY，存喺鑰匙圈。

游標同穿透

預設成個視窗穿透，游標越近元素越淡。按住修飾鍵時，只係游標下面嗰一個元素（加少少邊距）回復實色同可點擊；其他元素繼續按距離淡出。游標唔喺任何元素附近就冇變化。輸入框聚焦會保持中間面板可互動；設定頁打開會保持設定面板可互動。Esc、點空白，或者視窗失焦就離開。

Linux 視窗管理員常用 Alt 拖移視窗（xfwm4 預設，GNOME／KDE 都常見）。揀 Alt 之後，Alt+click 可能去唔到呢個程式，設定就開唔返。可以用快捷鍵 Ctrl+Shift+Alt+H，或者系統匣選單「設定」。
